# 바로문자

창을 띄우지 않고, 등록한 전역 단축키로 문자나 문구를 현재 입력칸에 바로 넣는 Windows 유틸리티입니다.

## 사용법

1. `QuickText.exe`를 실행합니다. 프로그램은 작업 표시줄 오른쪽 알림 영역에서 실행됩니다.
2. 트레이 아이콘을 더블클릭하거나 우클릭한 뒤 **설정 열기**를 누릅니다.
3. **추가**를 눌러 문자/문구와 단축키를 등록하고 **저장**합니다.
4. 메모장, 브라우저 등 원하는 입력칸에서 등록한 단축키를 누릅니다.

최초 실행 예시는 `Ctrl+Alt+1` → `✓`, `Ctrl+Alt+2` → `→`, `Ctrl+Alt+3` → `★`입니다. 설정에서 수정하거나 삭제할 수 있습니다.

설정은 `%LOCALAPPDATA%\QuickText\shortcuts.txt`에 저장됩니다. 관리자 권한으로 실행된 프로그램에 입력하려면 바로문자도 관리자 권한으로 실행해야 합니다.

앱 아이콘의 원본 이미지는 `assets/icon-source.png`, Windows 아이콘은 `assets/app.ico`에 있습니다.

## 다시 빌드하기

Windows PowerShell에서 `build.ps1`을 실행하면 같은 폴더에 `QuickText.exe`가 생성됩니다.
